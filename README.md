💻 Tareas de Programación Orientada a Objetos (POO)

Este repositorio contiene ejercicios desarrollados en C++ aplicando conceptos fundamentales de Programación Orientada a Objetos (POO).
Los programas fueron realizados como parte de las prácticas académicas de la carrera de Ingeniería de Sistemas.

---

📚 Descripción

El objetivo de este repositorio es aplicar conceptos importantes de programación como:

🔹 Uso de clases y objetos
🔹 Aplicación de métodos get y set
🔹 Validación de datos ingresados por el usuario
🔹 Implementación de lógica de programación en diferentes problemas

---

📂 Programas incluidos

📅 1. Validación de Fechas

Programa que permite verificar si una fecha ingresada por el usuario es válida.

Características del programa:

- 📥 Ingreso de día, mes y año
- ✔️ Validación de rangos correctos
- 📊 Verificación de fechas válidas dentro del calendario

Este ejercicio permite practicar control de datos y validación de entradas.

---

✊📄✂️ 2. Piedra, Papel o Tijera (POO)

Implementación del clásico juego Piedra, Papel o Tijera utilizando Programación Orientada a Objetos.

Características:

- 🎮 Interacción con el usuario
- 🤖 Jugada aleatoria de la computadora
- 🏆 Determinación automática del ganador

Este ejercicio aplica clases, objetos y lógica de decisión.

---

⚙️ 3. Ejemplo usando Get y Set

Programa que demuestra el uso de métodos Get y Set para acceder y modificar atributos de una clase.

Funciones del programa:

- 🔒 Encapsulación de datos
- 🔄 Modificación de valores mediante métodos
- 📋 Acceso controlado a los atributos de la clase

Este ejercicio permite comprender mejor el concepto de encapsulamiento en POO.
